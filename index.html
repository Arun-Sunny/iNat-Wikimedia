      Help

      Before you start

      1. A Wikimedia account. Create one if you don't have one; it works on all Wikimedia sites. You log in on Wikimedia's own page, so this app never sees your password.
      2. An open license on iNaturalist: CC0, CC BY or CC BY-SA. iNaturalist's default, CC BY-NC, isn't allowed on Commons. You can change the license of your past photos in your iNaturalist account settings.
      3. Recommended: add your Commons username to your iNaturalist profile, and a link to your iNaturalist profile on your Commons user page, so reviewers can see both accounts are yours.

      How to upload

      1. Step 1: paste the iNaturalist profile link, press Use this account, then Load photos. Tick These are my own photos only if you took them; otherwise they're credited to the iNaturalist photographer.
      2. Step 2: tap photos to select them, or press Add best photo of each species. Greyed-out photos can't go to Commons; their label says why.
      3. Step 3: press Check & preview to see exactly what will be sent. Log in with Wikimedia (top right), then press Upload. Each run uploads a few photos, one at a time, with a pause between them.
      4. Start with 2 or 3 photos and look at them on Commons before uploading more.

      New Wikimedia accounts are sometimes asked for a CAPTCHA, which this app can't show. If that happens, upload one file by hand on Commons, or wait until the account is a few days old and has 10 edits.

      Setting up the Wikimedia login (once per site)

      1. While logged in to Wikimedia, open the OAuth 2.0 registration form.
      2. Fill it in like this:
        Application name
        iNat to Commons
        Consumer version
        1.0
        Description
        Lets photographers upload their own openly licensed iNaturalist photos to Wikimedia Commons.
        "This consumer is for use only by …"
        Unticked
        OAuth "callback" URL
        Allow consumer to specify a callback
        Unticked
        Client is confidential
        Unticked
        Types of grants
        Request authorization for specific permissions
        Applicable grants
        Basic rights, Edit existing pages, Create, edit, and move pages, Upload new files (all four are needed: uploading a new file also creates its page)
      3. Submit, then copy the client application key. Ignore the secret and never paste it anywhere.
      4. Paste the key in Settings → OAuth client ID to use it in this browser, or put it in js/config.js in the code so it works for everyone.

      Until Wikimedia's administrators approve the registration, only the account that registered it can log in.

      Missed a permission? Permissions can't be changed after registering. Register again with the same name and a higher version (e.g. 1.1) and all four permissions, paste the new key, then log out and log in again.
